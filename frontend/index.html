🔧 Under the Hood

How It Works

Five-step ML pipeline from raw text to a confident prediction.

1
📝 Input News Text

User submits a headline or full article via the web interface. Client-side validation ensures minimum quality before sending.

2
🧹 Text Preprocessing

NLTK pipeline: lowercase → strip HTML/URLs → remove punctuation → eliminate stopwords → apply Porter Stemmer for normalization.

3
📊 TF-IDF Vectorization

Converts cleaned text into a sparse numerical feature matrix using Term Frequency-Inverse Document Frequency with bigrams (15,000 features). The fitted vectorizer is saved and reused.

4
🤖 ML Classification

The pre-trained best model (selected from Logistic Regression, Naive Bayes, SVM, or Random Forest) predicts REAL or FAKE with a calibrated confidence probability.

5
✅ Result & Explanation

The Flask API returns the label, confidence score, and a context-aware explanation. The frontend animates the result card and confidence ring for visual clarity.
